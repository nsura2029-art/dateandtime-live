Ad slot system

Ad slots are static placeholders now, but architected for dynamic insertion later. We have a working design system (.ad-slot with 4 variants from commit dd8c63628). 4 standard sizes, all responsive.

SlotSizePlacementBehavior
Ad 1 — Leaderboard 728×90 (320×50 mobile) Between hero and tabs Always visible. Above the fold on desktop.
Ad 2 — Sidebar 300×600 (300×250 mobile) Right sidebar, sticky Sticky on scroll. Hidden <1100px. Highest CPM slot.
Ad 3 — In-content 728×90 (300×250 mobile) Inside long sections (Time Zone history table, News) Centered, with margin. CLS reserved.
Ad 4 — Bottom 970×250 (300×250 mobile) After last tab pane, before continue strip Always visible. Last impression before user navigates away.

Ad loading strategy

  • Ad 1 (Leaderboard) — Eager load. Above fold.
  • Ad 2 (Sidebar) — Lazy load on scroll into view (IntersectionObserver)
  • Ad 3 (In-content) — Lazy load when user scrolls past 50% of section
  • Ad 4 (Bottom) — Lazy load on scroll within 600px of viewport
  • Refresh — Ads refresh on tab change (capped to 1 refresh per 30s to prevent CLS abuse)

No-ad fallback (premium / future)

When a user has a "no ads" preference (cookie/localStorage), all 4 slots collapse to 0 height. Layout reflows. Or, if we go freemium later, signed-in subscribers see no ads.

JS architecture

// Tab activation flow
const tabs = document.querySelectorAll('.tab');
const panes = document.querySelectorAll('.tab-pane');

tabs.forEach(tab => {
  tab.addEventListener('click', (e) => {
    e.preventDefault();
    const targetId = tab.getAttribute('href').slice(1); // #weather → weather
    const pane = document.getElementById('pane-' + targetId);
    
    // Update URL (no reload)
    history.replaceState(null, '', '#' + targetId);
    
    // Toggle active state
    tabs.forEach(t => t.classList.remove('active'));
    tab.classList.add('active');
    panes.forEach(p => p.classList.add('hidden'));
    pane.classList.remove('hidden');
    
    // Smooth scroll
    pane.scrollIntoView({ behavior: 'smooth', block: 'start' });
    
    // Lazy fetch if not yet loaded
    if (!pane.dataset.loaded) {
      loadTabData(targetId, pane);
    }
  });
});

async function loadTabData(tabId, pane) {
  pane.classList.add('loading');
  const cityId = document.body.dataset.cityId;
  
  const apiMap = {
    'weather': `/api/v1/cities/${cityId}/weather`,
    'time-zone': `/api/v1/cities/${cityId}/dst`,
    'sun-moon': `/api/v1/cities/${cityId}/sun`,
    'news': `/api/v1/cities/${cityId}/news`,
  };
  
  if (apiMap[tabId]) {
    const res = await fetch(apiMap[tabId]);
    const data = await res.json();
    renderTabContent(tabId, pane, data);
  }
  pane.dataset.loaded = 'true';
  pane.classList.remove('loading');
}

// On page load, check URL hash and activate that tab
window.addEventListener('load', () => {
  const hash = window.location.hash.slice(1);
  if (hash) {
    const tab = document.querySelector(`.tab[href="#${hash}"]`);
    if (tab) tab.click();
  }
});
