💡 Key Insights

🌆 78% of cities missing from our DB

Dataset has 152,970 cities. Our DB has 33,945. We're missing 119,025 — mostly city, adm2, and adm3 types. The dataset uses GeoNames-style hierarchy we don't currently ingest.

🔑 Different ID space

Only 739 city IDs overlap between this dataset and our DB. The dataset has its own ID space (max city_id is much higher). To merge, we need to match on (name + cca2 + state) — not on ID.

🌍 All 223 countries covered

We have 242 countries vs dataset's 223. Our DB is more complete for territories (we include 21 extras: AI, CC, CK, CW, GI, MO, MS, NF, PN, SH, SJ, SX, TC, VA, VG, etc.)

📍 401 states missing

Dataset has 4,266 states; our DB has 3,865. Most of the gap is in adm2 (counties/departments) and section types that we filtered out.

🌐 22 subregions match

UN M49 subregions: dataset has 22, ours has 25 (we split Americas into 4 = N. America, S. America, Caribbean, Central America). Dataset groups Americas as 1 region with 4 subregions.

⏰ 90% timezone overlap

Dataset has 371 IANA timezones, ours has 356. Intersection is 334. Missing 37 (mostly small North American zones like America/Adak, America/Nome). Our DB has 22 zones the dataset doesn't (more granular European/Atlantic zones).

🏛️ Rich country metadata

Each country in this dataset includes: capital, currency code, phone code, emoji, ISO2, ISO3, population, region, subregion. We have most of this but spread across multiple tables.

🏘️ State native names available

Dataset has state_native field (e.g. Arabic for provinces, Hindi for Indian states). We don't store native state names yet. Would help with localization.
